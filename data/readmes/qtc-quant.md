# qtc-quant

Trading platform for a student algorithmic trading competition. Teams upload Python strategies, which run every minute against live market data and place orders through Alpaca.

It logs trades and portfolio history per team, and serves an HTTP API and a public leaderboard.

**Stack:** Python, FastAPI, Alpaca, Parquet, Next.js
